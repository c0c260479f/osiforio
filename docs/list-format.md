# リストのデータの形（version 1）

1つのリストは、次の形のJSONです。共有リンクにも、記録の保存にも、この形がそのまま入ります。

```json
{
  "format": "oikake-list",
  "version": 1,
  "id": "l3k9x0abc",
  "title": "ほしぞら組 追いつきリスト",
  "work": "ほしぞら組（架空のアイドルユニット）",
  "author": "作者の名前",
  "checkedAt": "2026-10-26",
  "updatedAt": "2026-11-05",
  "description": "どんな人向けの追い方か",
  "unofficial": true,
  "reportUrl": "https://docs.google.com/forms/d/e/.../viewform?entry.123={title}",
  "links": [
    { "label": "公式サイト", "url": "https://example.com/" }
  ],
  "types": [
    { "id": "song", "label": "曲" },
    { "id": "story", "label": "ストーリー" }
  ],
  "items": [
    {
      "id": "i8f2k1m0q",
      "type": "song",
      "title": "曲名",
      "date": "2024-05-16",
      "url": "https://example.com/song",
      "note": "短い説明（自分の言葉で）",
      "spoiler": false
    }
  ],
  "routes": [
    { "id": "main", "label": "作者のおすすめ順", "order": ["i8f2k1m0q"] }
  ],
  "terms": [
    { "id": "w1", "word": "用語", "note": "用語の説明", "after": "i8f2k1m0q" }
  ],
  "goal": "i8f2k1m0q"
}
```

## 決まりごと

| 項目 | 決まり |
| --- | --- |
| `id`（リスト・項目） | 一度決めたら変えない。チェックの記録は項目の `id` にひもづくので、タイトルを直してもリストを更新しても記録は消えない |
| `checkedAt` | リストの中身を最後に確かめた日（`YYYY-MM-DD`）。画面に「最終確認」として出る |
| `updatedAt` | リストを最後に編集して保存した日（`YYYY-MM-DD`）。画面に「〇〇版」として出る。同じリストを開き直したときに、手元の版と比べられる |
| `color` | 推しカラー。`#` と6桁の16進数（例：`#3cc4f0`）。そのリストのボタンや「次はこれ」などがこの色になり、文字は読める濃さに自動で調整される。空ならアプリの標準の色（無彩色）。この形でない値は読み込むときに捨てる |
| `goal` | 布教の型の区切り。「ここまで見れば話がわかる」の最後の項目の `id`。入っていると、作者のおすすめ順が「まずこの1つ」「ここまで見れば話がわかる」「もっと知りたくなったら」の3段に分かれて表示される。空なら分けない |
| `unofficial` | 「非公式」の表示。このアプリが扱うのはファンが作るリストだけなので、読み込むときも保存するときも常に `true` にする（`false` で読み込んでも `true` になる） |
| `reportUrl` | 間違いの報告先。`{title}` は項目のタイトルに置き換わる。空なら報告リンクを出さない |
| `types` | 種類（入り口）。画面の「曲から」「ストーリーから」の絞り込みに使う |
| `items[].url` | 公式ページへのリンク。`https://` か `http://` だけを受け付け、それ以外は読み込み時に捨てる |
| `items[].date` | 公開日（`YYYY-MM-DD`）。わからなければ空でよい |
| `items[].spoiler` | `true` の項目は、チェックするまで説明を隠す |
| `routes` | 並び順。先頭は必ず `main`（作者のおすすめ順）。「公開順」は `date` から自動で作るので入れない |
| `terms[].after` | その項目をチェックするまで、用語の説明を隠す。空ならいつでも表示する |
| 上限 | 項目は1,000件まで。長すぎる文字は読み込み時に切る |

## チェックの記録（端末にだけ保存）

```json
{
  "progress": {
    "l3k9x0abc": {
      "checked": { "i8f2k1m0q": "2026-10-26" },
      "route": "main",
      "filter": "all"
    }
  }
}
```

共有リンクには記録を入れません。記録の保存（コピーやファイル）には、リストと記録の両方が入ります。

## 共有リンク

リストのJSONを `deflate-raw` で圧縮し、URLで使える Base64（`-` と `_` を使う形）にして、先頭に `z` を付けたものを `#list=` のあとに入れます。`#` の前には `?openExternalBrowser=1` を付けます。LINEでこのリンクを開くと、アプリの中のブラウザではなく、ふだんのブラウザで開くようになります（記録がふだんのブラウザに残るように）。圧縮が使えないブラウザでは、圧縮せずに先頭へ `j` を付けます。`#` より後ろはサーバーに送られないので、リストの中身がサーバーに残ることはありません。
