# 追いつきリスト

長く続く作品に途中からハマった人が、「何から・どの順で追えばいいか」をリストで確かめて、チェックしながら追いつけるWebアプリです。

**公開ページ**：https://c0c260479f.github.io/osiforio/

> 試作版です。最初は使い方を試すための架空のサンプルリストが入っています。

## できること

- 追いつき度のメーターと、「次はこれ」のおすすめ
- 布教の型：作者のおすすめ順を「まずこの1つ」「ここまで見れば話がわかる」「もっと知りたくなったら」の3段に分けて見せる（区切りは編集画面で選ぶ。なくてもよい）
- 並び順（作者のおすすめ順／公開順）と、入り口（曲から・ストーリーからなど）の切り替え
- リンクの横に、リンク先のサイト名を表示する
- ネタバレ配慮：チェックするまで隠れる説明と用語メモ
- リストの作成と編集（1行ずつ貼り付けて、まとめて足すこともできる）
- 共有リンク：リストの中身をURLに入れて渡す。LINEではふだんのブラウザで開き、ほかのアプリの中で開いたときは「ブラウザで開いてください」と案内する
- 記録の保存：コピーかファイルで保存して、別の端末で読み込む
- ホーム画面に追加して、アプリのように使う

## しくみ

- サーバーを持たない静的サイトです。リストとチェックの記録は、使う人のブラウザにだけ保存されます。
- 共有リンクは、リストを圧縮して `#list=` のあとに入れたものです。`#` より後ろはサーバーに送られません。
- `index.html` 1つで動き、ビルドはいりません。`manifest.webmanifest` と `sw.js` で、ホーム画面への追加とオフラインでの表示に対応しています。
- リストのデータの形は [docs/list-format.md](docs/list-format.md) にまとめています。

## 動作確認

```
pip install playwright
python -m playwright install chromium
python tests/smoke_test.py
```

スマホの画面幅で、チェック・入り口の切り替え・共有リンク・編集・記録の保存と読み込みを一通り動かします。画面のスクリーンショットは `tests/screenshots/` に保存されます。

## リストを作る人へ

- このアプリのリストは利用者が作る非公式のものです。公式とは関係ありません。
- 曲名や日付などの事実と、自分の言葉で書いた短い説明だけを載せてください。歌詞、画像、公式の文章は載せないでください。
- 各項目には、公式ページへのリンクを付けてください。無断でアップロードされた動画などにはリンクしないでください。
- アプリが防げるのは画像だけです。歌詞を書かないことと、リンク先を公式にすることは、作る人が守ってください。
